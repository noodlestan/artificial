# Art Mantras

> Interactive curator for the A.R.T.I.F.I.C.I.A.L.S acronym.

Generates mantra options for the ART acronym from per-letter word pools. Random mantra composition, strong promotion, banning, reordering, and saved mantras. Vanilla JS micro app, no build; state persisted in `src/data.json`.

This package is part of the [artificials](../../../README.md) toolkit.

## Development

Make sure you read the [namespace README](../../README.md) first.
