# Module: Art Mantras

Binds the shared module workflow to this module's files. The structure of the plan and pseudo documents and the next-move commands are shared and live in `artificials/_module.md`; run a command when the user says `command: <name>`.

**Binding:** `%plan` = `_plan.md`, `%pseudo` = `_pseudo.md`, `%wip` = `_wip.md`. Conventions and principles follow **Artificials Fundamentals**, not this module.

## Commands

- `command: break down responsibilities` — see `artificials/_module.md` → Command: break down responsibilities
- `command: tighten plan` — see `artificials/_module.md` → Command: tighten plan
- `command: abstract` — see `artificials/_module.md` → Command: abstract
- `command: Pre Commit` — see `artificials/_module.md` → Command: Pre Commit
- `command: record delegation` — see `artificials/_module.md` → Command: record delegation
