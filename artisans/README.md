# Artisans

> Hand-crafted micro applications for humans working with Art and Artificials.

No-build vanilla HTML/CSS/JS apps. State lives in plain JSON files next to each app. Each app is served with a single zero-dependency node http script.

## Apps

- [Art Mantras](./apps/art-mantras/README.md) — Interactive curator for the A.R.T.I.F.I.C.I.A.L.S acronym.
