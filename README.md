# Artificials

> Generate and manage (Art)ificial Driven Development environments.

A collection of tools and resources to generate and manage knowledge artefacts and agent instructions.

## Development

### Scripts

- **$** `npm run turbo build` — Build all packages.
- **$** `npm run turbo test` — Run tests in all packages.
- **$** `npm run turbo lint` — Lint all packages (Prettier + ESLint).
- **$** `npm run ci` — Run all CI scripts in all packages.
