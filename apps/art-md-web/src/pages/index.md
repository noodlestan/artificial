## Features

### Extensible

An open construct registry allows new structures and declarations to be defined without
changing the underlying parser. Constructs define how Markdown is recognised, represented,
validated, transformed, and serialised.

### Transformable

Art MD content can be parsed, validated, transformed, and serialised programmatically,
enabling automated generation, extraction, and transformation.
